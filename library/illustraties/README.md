# Illustratiebibliotheek MijnPil.nu

Bronbeelden voor social posts, in de huisstijl. Basis is meestal 16:9.

## Aanleveren

- Sleep de bestanden in deze map via github.com: open de map, kies
  Add file, dan Upload files. Maximaal 100 bestanden per keer, 25 MB per bestand.
- PNG of JPG is prima. Heb je ook de SVG, lever die dan met dezelfde naam mee.
- Submappen per onderwerp mogen, bijvoorbeeld `pil/`, `menstruatie/`, `overgang/`.
- Geen spaties in bestandsnamen: gebruik koppeltekens of underscores.

Let op: deze repository is publiek. Alleen marketingbeeld, nooit
ongepubliceerde of vertrouwelijke bestanden.
